\section{Methodology}
\begin{itemize}
    \item Consider the low Reynolds limit, where inertia is negligible 
    \item We define a lattice of $i=1,2,\ldots,N_x$ by $j=1,2,\ldots,N_y$, and take $N_x=N_y=N$ for simplicity.
    \item Each lattice site/element is considered to be a mesoscopic region of the material, typically approximately the size of a rearrangement event (bond or cluster of particles)
    \item Each element has a local strain $l$, a corresponding local shear stress $\mu l$, and a local yield energy $E$.
    \item The material is assumed to undergo a globally applied bulk strain $\gamma$, which is assumed to be applied affinely to the material.
    \item Each element is assumed to follow the same set of rules
    \begin{enumerate}
        \item Each element is assumed to strain elastically by default ($l \to l + \gamma$, where $\gamma$ is the globally applied strain).
        \item Each element has a local yield criterion ($\frac{1}{2} \mu l^2=E$) which determines the onset of a plastic event.
        \item Upon yielding a element adopts a new local strain chosen at random from a Gaussian distribution of width $l_w$.
        \item The elastic stress lost from a plastic event is redistributed to neighbouring blocks through the Eshelby stress propagator (defined in \cref{sec:EshelbyPropogator})
    \end{enumerate}
    \item Breakdown rules more precisely
    \begin{enumerate}
        \item Between plastic events, the strain of each element affinely follows the globally applied strain $\gamma$, corresponding to elastic loading with $\dot{l}=\dot{\gamma}$
        \item Work in units where the elastic constant $\mu=1$ and $E=1$ such that the critical strain $l_c = \pm 1$
        \item The plastic event forces a rearrangement of particles; the system is not in force balance, which needs to be reimposed. This is done by yielding the element and applying force balance using \cref{eq:eshelbyReal}.
        \item Define the propogator here, make it clear the constant at $\hat{G}[0,0] = -1$ such that the total lost stress is conserved.
        \item define both $Origin$ and $\Norm$ here for use later.
        \begin{figure}[hbt]
            \centering
            \includegraphics[width=0.9\textwidth]{chapters/Fatigue/Diagrams/Prop.pdf}
            \caption{}
        \end{figure}
        \item We assign the inital distribtuion of local strains $l$ from a gaussian distribution of width $l_0$. We then immediatly impose force balance on the system which has the effect of scaling the distribution of local strains by a factor $\Norm$.
    \end{enumerate}
    \item We then apply an oscillatory shear strain $\gamma(t) = \gammaMax \sin(\omega t)$, with rate $\dot{\gamma}(t) = \omega \gammaMax \cos(\omega t)$, and observe the evolution of the system.
    \item We concider the rate where $\omega \to 0$ such that the system is always in a quasi-static state, and the system is allowed to relax after each plastic event.
    \item Describe Implementation of jumping to next plastic event and then evolving any avalances. 
    \item define macrosopic shear stress
    \[\Sigma = \frac{\mu}{2}\sum_{i=1}^{N_x}\sum_{j=1}^{N_y} l_{ij}.\]
\end{itemize}
